# Explore a populated demo week

[`demo-week.json`](demo-week.json) contains 15 fictional tasks for a fixed week, 6-12 September 2026. It is the shared dataset for the repository and portfolio screenshots, not a record of anyone's real schedule.

1. Save the JSON file locally and open the app.
2. Choose **Import**, select the file, and confirm replacement if the app already contains tasks. Import replaces the current week; export a browser backup first if needed. Android export is unavailable in this build, so use disposable demo data there.
3. Explore **Week view** and **Day view**. Work/Life labels, priorities, completed tasks, and daily capacity are already visible.
4. Open **Plan my week**, keep **Fixture demo**, and choose **Generate proposal**. The initial fixture proposes moving **Map onboarding flow** from Sunday to Saturday, the lightest day. It does not call a model or change saved tasks.
5. Review the before/after details. **Approve all changes** applies the validated proposal; **Dismiss proposal** leaves the week unchanged. Changing a task while reviewing makes the proposal stale.

The dates intentionally stay fixed so the example and screenshots can be compared. The Today marker and initial day selection depend on the current date. Reimport the file to restore the original demo; identifiers are regenerated by the normal importer. The app does not seed or overwrite existing data automatically.
