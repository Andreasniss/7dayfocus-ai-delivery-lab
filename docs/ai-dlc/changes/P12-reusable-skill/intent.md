# Reusable delivery skill

Andreas requested an independent skill based primarily on Anthropic's official AI-native SDLC guidance, piloted in 7DayFocus and Runbook Relay before wider adoption. The agreed scope is proportional planning, preservation of existing repository rules, verification tied to the candidate revision, fresh review, and genuine release boundaries. Andreas authorized implementation on 2026-09-06 after reviewing that approach.

Success means one portable skill works with both repositories without replacing their instructions or claiming that prose enforces permissions. Public evidence must distinguish deterministic checks, agent behavior, and production readiness. No community implementation is copied. No application features, live-model calls, or production deployment are required for the pilot.
